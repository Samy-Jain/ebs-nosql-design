# LaTeX Source

Place the `ebs_report.tex` file here.

The compiled PDF is available in `../docs/ebs_report.pdf`.

To compile:

```bash
pdflatex ebs_report.tex
pdflatex ebs_report.tex   # run twice for TOC and references
```

**Requirements:** TeX Live or MiKTeX with packages: `geometry`, `fontenc`, `microtype`, `graphicx`, `booktabs`, `longtable`, `tabularx`, `multirow`, `hyperref`, `listings`, `xcolor`, `amsmath`, `amssymb`, `titlesec`, `parskip`, `setspace`, `fancyhdr`, `caption`, `float`, `enumitem`.
